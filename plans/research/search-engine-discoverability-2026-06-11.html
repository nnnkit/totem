Manual search-engine setup

Priority Channel Action Evidence / source
1 Bing Webmaster Tools Verify usetotem.xyz, submit https://usetotem.xyz/sitemap-index.xml, then check sitemap status, last read date, and crawl/indexing errors. Bing says sitemaps can be discovered from robots.txt or submitted in Bing Webmaster Tools, and recommends monitoring sitemap status and errors: Bing sitemap guidance.
2 IndexNow Generate an IndexNow key, host a UTF-8 key file at apps/site/public/<key>.txt containing the key, deploy it, then run: INDEXNOW_KEY=<key> pnpm seo:indexnow. Use pnpm seo:indexnow -- --dry-run before submitting. IndexNow requires an API key, hosted key file, URL submission, and verification: Bing IndexNow setup. IndexNow participants share verified URL notifications with other participants: IndexNow search-engine documentation.
3 Google Search Console Verify the property and submit https://usetotem.xyz/sitemap-index.xml. Use URL Inspection for the homepage, blog index, and the highest-priority blog posts after deployment. Google says sitemaps should use fully qualified canonical URLs and can be submitted in Search Console or referenced in robots.txt: Google sitemap docs.
4 Brave Search Do not look for a general Brave sitemap submission flow. Keep pages crawlable to Googlebot, do not block CSS/JS/assets, and use Brave's refetch/delist flow only if Brave shows stale or removed URLs. Brave says its crawler discovers pages like other search engines, does not advertise a separate user agent, and will not crawl pages that are not crawlable by Googlebot: Brave Search crawler docs.
5 DuckDuckGo Treat Bing setup as the main lever for ordinary DuckDuckGo blue-link discovery. Also keep robots.txt and the sitemap clean for DuckDuckBot. DuckDuckGo says it maintains DuckDuckBot and its own indexes, but traditional links and images are largely sourced from Bing: DuckDuckGo result sources.
6 Yahoo / Ecosia-style Bing syndication No separate first pass. Finish Bing Webmaster Tools plus IndexNow first, then check brand and article queries in each search surface. Bing coverage is the highest-leverage input for many secondary engines.
7 Microsoft Edge Add-ons If the extension works in Edge, publish a Microsoft Edge Add-ons listing with the same screenshots, privacy claims, and canonical homepage link. This is browser-store discovery, not web SEO, but it helps Bing/Edge users find the product. Requires Microsoft Partner Center access and a compatibility check.
8 Chrome Web Store listing Refresh listing copy around the strongest search phrases already used on the site: Twitter bookmark manager, X bookmark search, export Twitter bookmarks, Chrome new tab reading queue. Keep screenshots current with the homepage and blog claims. Requires Chrome Web Store developer access.

Deployment checklist

  1. Deploy the website build that contains these metadata, sitemap, and llms.txt updates.
  2. Open https://usetotem.xyz/robots.txt and confirm it references https://usetotem.xyz/sitemap-index.xml.
  3. Open https://usetotem.xyz/sitemap-index.xml and confirm /uninstall-feedback/ is absent.
  4. Verify Bing Webmaster Tools and Google Search Console, then submit the sitemap index in both.
  5. Generate and deploy an IndexNow key file, then run INDEXNOW_KEY=<key> pnpm seo:indexnow.
  6. Check brand queries and priority post queries in Bing, Brave, DuckDuckGo, and Google 48-72 hours after submission.
