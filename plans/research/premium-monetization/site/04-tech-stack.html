Tech Stack — What Is New

Totem stays exactly as it is — MV3, React 19, Zustand, IndexedDB/idb, Vite, Astro site. The premium layer adds a small, deliberately boring surface on top.

The added surface

Nothing here replaces the existing stack; each row is a narrow, self-contained addition chosen to preserve the local-first, no-server ethos.

ConcernChoiceWhy
Checkout + tax Merchant-of-record: Lemon Squeezy (primary) or Polar (cost-optimized) MoR remits global VAT/GST, so the solo dev never registers for tax anywhere. No Totem billing server.
License keys Provider-issued license keys (Lemon Squeezy / Polar) The MoR mints and emails the key on a paid order — no separate signer, no key-management vendor, no private signing key to host.
License verification Online validate via the provider's license API — once at activation + a quiet periodic background re-check Validating data (JSON) is MV3-legal. Result is cached in CS_ENTITLEMENT and read locally thereafter; fail-open on network errors. Only key + email leave the device.
Device management Provider activation limit (~5) + self-serve deactivate page (its customer portal) Resolves multi-browser activation: a real person's few devices are fine; mass key-sharing is capped. Counting requires the online check.
Entitlement storage New SW-owned chrome.storage.local key CS_ENTITLEMENT Single-writer, reset-surviving, rides the existing reactive snapshot channel. Holds the cached validate result.
Pricing/license pages New static Astro pages on usetotem.xyz Site is 100% static; pages are static + client <script>, no backend.

No Totem server

Checkout, tax, key issuance, and device counting all live with the merchant-of-record. The extension talks to the provider's API (one host permission), never to a Totem-run backend. The MoR's secret API key stays server-side and never enters dist/ — the validate call a public client makes needs no secret.

NET EFFECT
The only network the extension does for licensing is a small validate call at activation and an occasional background re-check — never a per-launch phone-home, and never anything touching bookmark data. Verify online, but read from cache and fail open, so an outage can't lock out a buyer.
