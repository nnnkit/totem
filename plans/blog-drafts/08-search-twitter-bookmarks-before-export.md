## Post Packet

- Keyword cluster: ~110/mo across `twitter bookmarks search`, `search twitter bookmarks`, `x bookmarks search`.
- SERP evidence: `tmp/dataforseo/serp-export-launch-twitter-bookmarks-search-2026-05-28.json`.
- Product facts: Totem search supports free text, quoted phrases, `from:`, `site:`, `has:`, `filter:`, `since:`, `until:`, `within:`, `older_than:`, `OR`, and negation. Totem exports the full library ZIP, not arbitrary selected search results.

## Fragments

- Exporting before search is moving boxes before opening them.
- Native X search helps retrieve, but does not answer backup/restore questions.
- Search operators are export decisions: threads, links, media, old saves.
- Be honest: Totem does not export only the search result subset today.
- Search tells you whether basic export is enough or full export is worth waiting for.

## Beat Map
