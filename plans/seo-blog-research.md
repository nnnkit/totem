4. The "but my bookmarks disappeared / went public" misconception — links to the limit/disappearing post (Post 3).
5. Account privacy edge case: if you bookmark a public tweet then make your account private, the bookmark is still there for you. Nothing changes for the author.

People hitting these searches are **frustrated, active bookmark users** —

### What currently ranks for "twitter bookmarks limit"
1. reddit.com/r/Twitter — "Twitter Bookmark limits — How it actually works"
2. tweetarchivist.com (also ranks for the privacy query — they're the SEO competitor to beat)
3. x.com/mytwillot — Twillot's claim of "200,000 bookmarks stored"
4. circleboom.com — "All About Twitter Bookmarks Limit"
5. devcommunity.x.com — official forum thread "There are no limits on number of bookmarks stored?"
6. saverything.com — "Twitter Bookmarks Limit in 2026"
7. xbase.so — "Is there a bookmark limit on X?"
8. devcommunity.x.com — "How to get more than 800 bookmarks?" ← API limit thread
9. Medium — "I Crack the Code to Twitter's Bookmarks"

**Gap**: posts conflate three different things — the *display* limit (~800–1,000 visible in the X UI), the *API* limit (800 most recent via the bookmarks endpoint), and the *underlying storage* (no hard cap; Twillot users have 200k+). We can write the post that finally separates them clearly.

### People Also Ask
- "Why can't I see all of my bookmarks on Twitter?"
- "Why does Twitter keep removing my bookmarks?"
- "Is there a maximum amount of bookmarks?"
- "Is there a limit to your bookmarks on Twitter?"

The PAA answers in the SERP are wrong/contradictory — one says "no limit," another says "Twitter removes older bookmarks." This is the post's hook: **everyone is confused, here is the real answer.**

### Angle / outline
**Title**: "Why your Twitter/X bookmarks 'disappear' — the real bookmark limit, explained"

1. **One-line answer up top**: The X app shows you roughly the latest 800–1,000 bookmarks. Older ones aren't deleted — they're just hidden. The X API confirms this with an 800-most-recent cap on the official endpoint.
2. The three "limits" people confuse:
   - **Display limit** (what you see in the X bookmarks tab): ~800–1,000
   - **API limit**: 800 most recent via official endpoint
   - **Storage limit**: none publicly stated; some users have 200k+
3. Why this matters: if you're a heavy bookmarker, **older bookmarks are inaccessible without a third-party tool** that scrapes/indexes them.
4. How to "get them back": tools that index bookmarks before they fall off the visible cliff (Dewey, Twillot, **Totem** — local-first option). Honest comparison.
5. How to "clear all bookmarks" (the secondary search intent — many of these searchers want to delete, not preserve). Briefly cover the manual flow + extensions that bulk-delete.
6. Why Totem helps: indexes locally as you scroll, so even if X stops showing them, *you* still have them.

### Soft CTA hook
> "If you've ever searched for 'twitter bookmarks disappeared,' Totem is the
> answer. It captures your bookmarks into local storage in your browser, so
> nothing falls off the X display cliff again — and it shows them on every new
> tab so you actually read them."
